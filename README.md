# OM Bird Netting Services

A premium static business website for OM Bird Netting Services in Nagpur, Maharashtra. Built for GitHub Pages and designed as a professional local service website.

## Project Structure

```text
Birdnet/
├── index.html
├── style.css
├── script.js
├── favicon.svg
├── README.md
```

## Local Preview

Open `index.html` directly in the browser, or run a simple local server from the project folder:

```bash
cd Birdnet
python -m http.server 8000
```

Then visit:

```text
http://localhost:8000
```

## Deploy to GitHub Pages

Run the following commands:

```bash
git init
git add .
git commit -m "Initial OM Bird Netting website"
git branch -M main
git remote add origin YOUR_REPOSITORY_URL
git push -u origin main
```

Then in GitHub:

```text
GitHub Repository
→ Settings
→ Pages
→ Deploy from branch
→ main
→ /root
→ Save
```

## Notes

- Fully static website with no backend required.
- Contact form opens WhatsApp automatically with the enquiry details.
- All paths are relative and compatible with GitHub Pages.
- Responsive layout for mobile, tablet and desktop screens.
